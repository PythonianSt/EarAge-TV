# Ear Age – Vercel / Smart TV Edition

Static HTML/CSS/JavaScript version converted from the Streamlit EarAge app.

## Files
- `index.html` – app pages
- `style.css` – responsive styling for TV / desktop / mobile
- `app.js` – test flow and result logic
- `sounds/` – pre-generated stereo WAV tones

## Vercel settings
- Framework Preset: **Other**
- Build Command: **leave blank**
- Output Directory: **leave blank** (root directory)
- Install Command: **leave blank**

No Python runtime and no requirements.txt are required.

## Important
This is a health-awareness activity, not pure-tone audiometry or a diagnostic hearing test.
Playback above 8 kHz depends strongly on TV/browser/DAC/speakers/headphones.
